# Grandl Rank Widget v3
Kişisel Android widget: grandl#wave (TR), yalnızca Solo/Duo.
- Rank / division / LP
- W/L ve win rate
- Günlük net LP değişimi
- OP.GG verisi ve LoL rank amblemi
- Yaklaşık 30 dakikalık WorkManager yenilemesi
- Manuel yenileme
- Yeniden boyutlandırılabilir kompakt widget

Build: AGP 8.7.3 / Gradle 8.9 / JDK 17 / compileSdk 35 / minSdk 26.
